# Commit Convention — HEAL Website

Format: `<type>: <short summary>`

- `feat:` New user-facing feature, page or component
- `fix:` Bug fix
- `docs:` Documentation changes (REQUIREMENTS.md, architecture)
- `style:` Formatting, CSS design tokens
- `refactor:` Code restructuring without logic changes
- `chore:` Build setup, dependencies, Astro/ESLint/Prettier config
- `test:` Unit or E2E tests
